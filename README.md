## 💡 About the Project

**Linkely** is a modern social media platform designed for sharing, connecting, and engaging with others.  
Users can register, create profiles, share posts with images, like and comment on others’ posts, and explore a personalized social feed.

Built using the **MERN stack (MongoDB, Express, React, Node.js)** and deployed on **AWS**, Linkely combines scalability, security, and a clean UI for a seamless experience.

---

## ✨ Features

- 🔐 **User Authentication** – Register, log in, and manage accounts securely with JWT.  
- 📝 **Create & Edit Posts** – Share your thoughts and media with the world.  
- ❤️ **Like & Comment** – Interact with posts in real time.  
- 📰 **User Feed** – Browse posts from other users dynamically.  
- 🖼️ **Image Uploads** – Attach photos to your posts (via Cloud Storage).  
- ☁️ **Cloud Deployed** – Hosted on AWS for high performance.  
- 📱 **Responsive Design** – Optimized for all screen sizes.
